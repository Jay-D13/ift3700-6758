# Tutoriels Git

Ces supports sont indépendants des démonstrations Python et des anciens labos.

| Langue | Support |
|---|---|
| Français | [Diaporama Git et GitHub](fr/tutoriel_git.pptx) |
| Anglais | [Diaporama Git et GitHub](en/git_tutorial.pptx) |
| Anglais | [Notebook pratique](en/git_tutorial.ipynb) |

Les diaporamas de Reyhane Askari et Arnaud Bergeron couvrent les commits, les branches, la fusion, les conflits et les dépôts distants. Le notebook accompagne la prise en main de GitHub et des commandes Git.

Les deux notebooks d’origine, `Mila_Git_Tutorial_ift6758.ipynb` et `Tutorial_git_anglais.ipynb`, étaient identiques octet par octet : une seule copie est conservée. Aucun notebook français distinct n’était présent. Les deux diaporamas sont conservés, car ils correspondent à deux langues.

Les supports sont conservés dans leur état d’origine; certaines captures d’écran de GitHub peuvent différer de l’interface actuelle. Pour s’exercer, utilisez un dépôt de test plutôt que le dépôt partagé du cours.
